# InfraDeck: первый релиз

Единая панель управления проектами и их серверами. Текущий объём реализации:

| ID | Сценарий | Приёмка |
| --- | --- | --- |
| AUTH-01 | Регистрация | Логин, пароль >=12 символов, подтверждение; уникальный login; Argon2id |
| AUTH-02 | Привязка Telegram | Одноразовая ссылка /start, личный чат, numeric user ID, authenticated webhook |
| AUTH-03 | Вход | Логин/пароль → отправка 8-значного OTP в Telegram → форма ввода → полная сессия |
| AUTH-04 | OTP | 30 секунд, 5 попыток на preauth, resend не сбрасывает бюджет, одноразовое atomic consume |
| AUTH-05 | Восстановление | 8 одноразовых резервных кодов; выдаются при первой полной авторизации |
| PRJ-01 | Проекты CRUD | Только свои проекты; name/description; карточки 3/2/1; подтверждение удаления |
| SRV-01 | Серверы CRUD | Внутри проекта; VPS/VM, hostname/IP, port, login; секреты не возвращаются |
| SRV-02 | SSH | Password/key/user certificate + matching private key, optional passphrase |
| SRV-03 | Проверка | Получение fingerprint → сверка по доверенному каналу → SSH authentication → короткий proof |
| SRV-04 | Повторная проверка | Сохранённые реквизиты; изменившийся host key отклоняется |
| SEC-01 | Изоляция | Проверка owner каждого project/server; до OTP проекты недоступны |
| SEC-02 | Секреты | TLS в production, JWE при отправке SSH, envelope AEAD в PostgreSQL; ключи вне БД |
| UI-01 | Интерфейс | React/Tailwind, dark-first zinc, orange; light theme; единые селекты; responsive |

Удаление проекта каскадно удаляет его записи серверов и реквизиты. Оно не
подключается к VPS/VM, не выключает и не удаляет реальные машины.
Изменение метаданных сервера не требует повторного ввода пароля. Изменение
подключения требует нового proof; редактирование любого connection input
сбрасывает proof. API принимает параметры подключения исключительно из proof.

Не входят: агенты, сервисы, нагрузка CPU/RAM, Grafana, переносы и рекомендации
мощности. Эти экраны исключены из первого релиза. Ротация Telegram-привязки и
операторский KMS-adapter — последующие изменения с отдельной приёмкой.
