# Правила: icon-system

Применяются при подключённом профиле `--project-rules standard` или явном
выборе владельца. Обязательные требования владельца не выдаются за стандарт
внешнего источника. Для существующего несовместимого проекта обозначь конфликт,
не меняй архитектуру без задачи на переход.

## Правила иконок

Сначала определи смысл и контекст: действие, объект, статус или декор.
Установи сетку, оптический вес, толщину, окончания линий и базовые размеры.
Повторное использование идёт через один SVG/компонент; цвет — через токен
или currentColor. Не смешивай разные оптические системы без явного решения.

Проверь геометрию на фактических 16/24/32/48px, а не только на увеличенном мастере.
Для сложной иллюстрации допустима отдельная упрощённая версия: не обещай читаемость
24px, если детали сливаются. Различимость соседних смыслов проверяй без подписи,
а при неоднозначности добавляй видимую подпись в продукте.

Иконка кнопки имеет доступное имя действия на контроле; декоративный SVG
скрыт от accessibility tree. Не называй кнопку по форме значка, если действие
другое. Проверь viewBox, обрезку, уникальность id при повторном размещении,
наследование цвета, контраст и обе темы. Coverage относится к поведению
обёртки, а не к количеству SVG paths. Выход: автономные SVG и таблица размеров.

Источник семантики: [WAI functional images](https://www.w3.org/WAI/tutorials/images/functional/), проверен 2026-09-14.
