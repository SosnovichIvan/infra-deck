# InfraDeck

Панель управления собственными сервисами и инфраструктурой: реестр VPS/VM,
развёртывания, нагрузка, пользователи, Grafana и управляемый перенос сервисов.

Статус: подготовка проекта. Приложение, агент и deployment ещё не реализованы.
Стек предложен в ADR; версии runtime будут закреплены при реализации компонентов.

Локальные проверки основы проекта:

```sh
make check
```

Нужны Git и Python 3.12+; для проверки GitHub Actions отдельно нужен
`actionlint` 1.7.7. Его запуск включён в CI.

Будущая структура: `apps/web`, `services/control-plane`, `services/agent`,
`contracts`, `infra`. Каталоги появятся вместе с реализацией и обязательными
тестами; CI отклоняет появление неизвестного runtime без регистрации проверок.
